# Reporte de participación PC2

Adaptación en LaTeX del formato Word de participación del curso: datos de la entrega,
comentario del team leader, tabla de participación y criterios de descuento.
Los tres integrantes están marcados como Cumplió, sin descuento.
El nombre del grupo se configura en `main.tex`.

```bash
cd tp/informe/participacion-pc2
bash compilar.sh
```

Requiere Tectonic. Genera `build/main.pdf` y
`output/pdf/CC65-Participacion-PC2-202620.pdf` desde la raíz del repositorio.
